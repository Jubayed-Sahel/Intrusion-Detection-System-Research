# Uncapped and independent-capture evaluation protocol

Locked before fitting or scoring the extensions. Both extensions are exploratory follow-ups to the source-holdout study.

1. Score all known-label rows from all eight GeNIS held-out CSVs and all 65 Gotham CSVs represented in the existing 16 source folds. Read full author files; do not cap, resample, or alter their natural recorded class mix. The 13 Gotham files absent from the original assignment are outside this comparison. Use exactly the 64 saved RF/XGBoost classifiers and preprocessors. Exclude Gotham Unknown and every raw test row whose connection key is in the respective capped fold-training set (a raw row can reveal overlap missed by the cap). Validate input and model hashes; retain source coverage, exclusion counts, raw label support and complete eligible confusion matrices. Evaluate all supported test labels including labels absent from training. Compare descriptively with capped results; extra rows can share connections and are not independent replications. This is a test-size/prevalence extension, not a full-data training experiment.
2. Train new binary RF and XGBoost variants exclusively on the original GeNIS training partition. Lock seed 42, original hyperparameters, class weighting, threshold/argmax and train-only preprocessing. Use two harmonized feature sets: protocol number and unordered transport ports; and these three plus observed duration in seconds and total packets. For the official separately captured Federated OCPP 1.6 testbed, use both provider Combined CSVs strictly as external test data, never the overlapping client views. Map TCP/UDP ports only, with missing ports otherwise; normalize protocol numbers; convert CICFlowMeter duration from microseconds to seconds and sum forward/backward packet counts. GeNIS duration is already seconds. These are comparable fields, not identical flow exporters or segmentation. The entire external release tested is provider-balanced (not natural prevalence); original provider normal and four attack labels remain in per-category coverage. Compare with the same reduced models on the original GeNIS test set. Neither this small external benchmark nor the uncapped source study validates analyst usefulness, external explanation fidelity or deployment performance.
